
`MSMS.py` is a python program that runs the some basic functions for a front desk system in a music school/program.

It first defines two classes that stores information about students and teachers separately, where class:
Student - stores Name, ID and enrolled instruments in a list
Teacher - stores ID and speciality

Using these two classes, the program is able to store all registered information in two lists. 
Where:
  - `student_db` stores student records
  - `teacher_db` stores teacher records

The python program allows the front desk to:
Register new students
Enrol a new instrument for a registered student
Find a student or a teacher by their name or speciality
List all students/teachers
Find students enrolled in specific instrument

Run code in VS code to run the entire program
Data is temporary and will be resetted every time the program was run again

Upon running, it will show an interactive menu. Where user can choose which function to run by inputting integer numbers. Or ‘q’ to exit the program.
